# Qubit — Quantum Computing & Cybersecurity

Qubit is a modern, responsive corporate website concept for a technology company specializing in quantum computing, quantum security, post-quantum cryptography, and advanced cybersecurity solutions. The website presents the company's services, technological expertise, and contact information through a professional, futuristic interface.

## Overview

The project showcases emerging quantum technologies and cybersecurity solutions designed to address the evolving security challenges of digital infrastructure. It features a dark visual theme, blue lighting effects, quantum-inspired graphics, and a responsive layout to deliver a professional user experience across desktop and mobile devices.

## Features

- **Home Page:** Introduction to Qubit, its technological vision, and expertise in quantum computing and cybersecurity.
- **Services Page:** Dedicated sections covering quantum computing consulting, post-quantum cryptography (PQC), quantum-safe cloud security, quantum key distribution (QKD) consulting, hardware security, software security, hybrid quantum-classical security, AI-powered cybersecurity, enterprise and government security, and quantum technology research and development.
- **Contact Page:** Company contact information with editable address, email, and phone number fields.
- **Responsive Design:** Layout optimized for desktop, tablet, and mobile screens.
- **Modern UI:** Dark backgrounds, blue accents, quantum-inspired visuals, and interactive interface elements.
- **Consultation Enquiries:** Buttons that direct visitors toward the contact or consultation section.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/D-Saketh/LaTerra_Qubit_Demo.git
   ```

2. Navigate to the project directory:

   ```bash
   cd LaTerra_Qubit_Demo
   ```

3. Open `index.html` in a web browser, or use a local development server in your code editor.

## Deployment

The website can be published for free using GitHub Pages:

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Save the settings and open the published website URL once deployment completes.

No custom domain or paid hosting is required.
